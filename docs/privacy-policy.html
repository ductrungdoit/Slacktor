Slacktor Privacy Policy

Last updated: August 24, 2026

Slacktor is a browser extension that translates messages displayed in Slack Web using an AI endpoint selected and configured by the user.

Data Slacktor Handles

  • Slack message text, thread context, message/channel identifiers, author display names, and timestamps needed for translation.
  • Text entered into Quick Translator.
  • The AI endpoint, model, API key, target language, consent, and extension settings entered by the user.
  • Local operational logs containing request metadata and errors. Logs do not include API keys or message text.

Use and Transmission

Slacktor uses data only to translate content, improve translation with thread context, cache results locally, maintain local history/context, and display diagnostics.

When translation is enabled or requested, the target text and applicable context are sent to the AI endpoint configured by the user. Slacktor does not operate a developer-owned backend server, and the developer does not receive this data.

Remote AI endpoints must use HTTPS. Plain HTTP is supported only for local endpoints on localhost or 127.0.0.1.

Local Storage and Retention

  • Settings and API keys are stored in Chrome local extension storage.
  • Thread context is retained locally for up to 30 days after observed activity.
  • Translation cache entries are retained locally for up to 7 days.
  • Quick Translator history and diagnostic logs are local and can be cleared in the UI.

Sharing and Limited Use

Slacktor does not sell data or use it for advertising, profiling, credit purposes, or developer human review. Data is transferred only to the user-selected AI endpoint as necessary for translation.

Slacktor's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

User Controls

Users can disable automatic translation, stop active requests, clear translation cache, history, and logs, or remove the extension to delete local extension data.
